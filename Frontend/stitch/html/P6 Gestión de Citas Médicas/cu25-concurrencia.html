Mecanismos

Dos capas de protección

1 · Índice único parcialcita_medico_bloque_unico sobre (médico, fecha, hora_inicio) para citas no canceladas.
2 · TransacciónEl INSERT corre dentro de una transacción; la violación del índice produce ROLLBACK automático.
3 · InterfazLa pantalla captura el error, muestra el aviso (A1 de CU24) y vuelve a consultar la disponibilidad.
CanceladasUn bloque cuya cita fue CANCELADA vuelve a estar libre: el índice excluye ese estado.
